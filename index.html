A smart light switch assistant built for easier everyday control.

BrightAssist is a prototype that mounts over a standard light switch, detects room motion, moves the switch with a servo, and syncs control state with a mobile app in real time.

Project Goal

Make existing switches easier to reach and automate.

The project focuses on a non-invasive smart switch design. Instead of rewiring a wall switch, a 3D-printed frame holds a microcontroller, motion sensor, battery system, and servo mechanism that can physically press the switch while the app provides remote control.

01

Automatic Lighting

A PIR motion sensor detects movement in the room and turns the light on automatically. After a hold period with no motion, the hardware can switch the light back off.

02

Remote App Control

The Flutter app lets a user register a device, see device status, switch between manual and automatic modes, and toggle the light from a phone or tablet.

03

No Wall Rewiring

The prototype uses a servo to move a normal light switch from the outside, keeping the build independent from household electrical wiring.

System Design

One shared state between the app, Firebase, and the device.

Mobile App Register devices, change modes, toggle lights
Firebase Stores device owner, status, mode, and activity data
ESP32-S3 Reads motion, syncs state, and commands the servo

Prototype Build

Built from practical hardware and a polished app interface.

Hardware

  • Adafruit ESP32-S3 microcontroller
  • PIR motion sensor
  • 8-channel PWM/servo controller
  • Servo-driven light switch mechanism
  • Battery-powered enclosure with optional plug-in power

Software

  • Flutter mobile app for iOS, Android, and web targets
  • Firebase Authentication for accounts
  • Firebase Realtime Database for device state
  • CircuitPython hardware script
  • Local settings file for Wi-Fi and Firebase secrets
