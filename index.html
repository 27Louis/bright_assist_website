Project Goal

Improve safety before and after a bathroom fall risk.

Bathrooms are dangerous for older adults because low lighting, wet floors, and hard surfaces can turn a small slip into an emergency. BrightAssist is designed around two ideas: prevent risk by turning on lights automatically, and research private fall detection using sensor data instead of cameras.

01

Automatic Lighting

A PIR motion sensor detects movement in the room and turns the light on automatically. After a hold period with no motion, the hardware can switch the light back off.

02

mmWave Fall Detection

A research module uses 60 GHz radar to track motion patterns such as fast downward movement, sudden stops, and inactivity, without video or audio recording.

03

Remote App Control

The Flutter app lets a user register a device, see device status, switch between manual and automatic modes, and toggle the light from a phone or tablet.

04

No Wall Rewiring

The prototype uses a servo to move a normal light switch from the outside, keeping the build independent from household electrical wiring.

Research Problem

Most bathroom safety products ask users to give up privacy, comfort, or simplicity.

Cameras are not appropriate for private spaces. Wearables can be forgotten or left uncharged. Emergency buttons require a person to press them after something has already gone wrong. BrightAssist explores a lower-cost system that can install over existing hardware, preserve privacy, and send useful alerts through software.

Lighting Module

A PIR sensor detects entry, an ESP32-S3 handles logic and cloud sync, and a servo flips the existing light switch through a 3D-printed faceplate-mounted shell.

Fall Detection Module

A separate mmWave concept integrates radar sensing with an ESP32 and LED-style housing, designed for camera-free bathroom monitoring and future smart-home compatibility.

Prototype Build

Built from practical hardware, sensor research, and a working app interface.

Hardware

  • Adafruit ESP32-S3 microcontroller
  • PIR motion sensor
  • 60 GHz mmWave radar sensor for advanced fall detection tests
  • 8-channel PWM/servo controller
  • Servo-driven light switch mechanism
  • 18650 rechargeable battery system and USB-C power
  • 3D-printed flame-resistant enclosure

Software

  • Flutter mobile app for iOS, Android, and web targets
  • Firebase Authentication for accounts
  • Firebase Realtime Database for device state
  • CircuitPython hardware script
  • Realtime status updates and event logging
  • Local settings file for Wi-Fi and Firebase secrets

Limitations + Next Steps

The prototype is promising, but real homes are the next challenge.

Current Limits

Fall detection identifies likely falls from motion patterns, not confirmed impact. Results can change with bathroom layout, sensor placement, user movement, and long-term battery behavior.

Future Improvements

Next steps include improving radar signal processing, testing in real homes or care facilities, refining caregiver dashboards, and supporting multiple rooms.
