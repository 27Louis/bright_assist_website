BrightAssist combines embedded sensing, cloud sync, and assistive design.

A Firebase-backed smart bathroom safety prototype with a Flutter app, CircuitPython hardware, PIR lighting automation, servo actuation, and an mmWave fall-detection research path.

Project Snapshot

BrightAssist is designed for independent living and bathroom safety. The working switch module turns lights on automatically and syncs state to Firebase. The research module studies 60 GHz mmWave radar for privacy-preserving fall detection.

Flutter app + Firebase + ESP32-S3 + PIR + Servo

System Architecture

One realtime loop connects app controls, database state, and physical actuation.

Flutter App Authentication, device registration, status display, manual mode, automatic mode, and light toggling.
Firebase Realtime Database Shared source of truth for device owner, light state, auto mode, descriptions, and timestamped data.
ESP32-S3 Hardware Reads PIR motion, moves the servo, posts activity data, and follows remote app state changes.

Hardware Stack

Non-invasive mechanical control keeps the prototype independent from household wiring.

Switch Module

  • Adafruit ESP32-S3 Feather
  • PIR motion sensor on digital pin D12
  • 8-channel Servo FeatherWing
  • TowerPro SG92R-style servo actuation
  • 3D-printed faceplate-mounted shell

Power + Enclosure

  • 18650 rechargeable battery system
  • USB-C power input
  • Mounting screws and fitted shell
  • Designed for bathroom installation constraints

Research Module

  • 60 GHz mmWave fall-detection sensor
  • ESP32-based radar processing concept
  • LED housing / smart-home integration path
  • No camera or wearable required

Software Design

The app and hardware use simple Firebase paths to stay synchronized.

Firebase Paths

devices/{deviceID}/isON devices/{deviceID}/isAuto devices/{deviceID}/ownerID devices/{deviceID}/description devices/{deviceID}/data usersDevices/{uid}/devices/{deviceID}

Control Logic

  • Auto mode: PIR motion triggers servo ON and Firebase updates.
  • Hold time: light can turn off after 5 minutes without motion.
  • Manual mode: app writes light state and hardware follows it.
  • Status posts include timestamp, light state, and health status.

Science Competition Experiment

The project tests both prevention and detection: lighting response and possible fall sensing.

97%

PIR Motion Detection

44 of 45 motion trials were detected. The setup used fast, normal, and slow doorway events with a 0.5 second detection rule.

87%

mmWave Fall Detection

39 of 45 controlled fall simulations triggered an alert within 2.0 seconds using a ceiling-mounted radar test configuration.

<3s

Alert Transmission Goal

The system target is fast caregiver notification through Wi-Fi, Firebase, and the connected app after a possible fall event.

Judging Rubric

Key science fair categories mapped to the project.

Problem

Bathroom falls are high risk, and many existing systems are expensive, forgotten, or privacy-invasive.

Engineering Solution

A non-invasive switch module plus radar research module for privacy-preserving safety support.

Testing

Controlled trials measured detection accuracy across motion and simulated fall speeds.

Limitations

Fall detection is based on motion patterns and needs more real-home testing before final claims.
